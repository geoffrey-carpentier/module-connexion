# Wireframes - Module Connexion

Ce dossier contient les spécifications pour les wireframes du module de connexion.

## Pages à créer

Les wireframes doivent être créés pour les 5 pages suivantes, en version **desktop** et **mobile** :

1. **Accueil** (index.php)
2. **Connexion** (connexion.php)
3. **Inscription** (inscription.php)
4. **Admin** (admin.php)
5. **Profil** (profil.php)

## Outils recommandés

- **Figma** : Pour créer les wireframes et maquettes
- **Figma Community** : Pour trouver des templates de wireframes existants

## Structure des wireframes

Chaque page doit inclure :
- **Header** : Menu de navigation
- **Contenu principal** : Spécifique à chaque page
- **Footer** : Informations et liens

## Résolutions cibles

### Desktop
- Largeur minimale : 1024px
- Largeur recommandée : 1440px

### Mobile
- Largeur : 375px (iPhone standard)
- Largeur alternative : 360px (Android standard)

```css
Danger : #dc3545 (Rouge)

```

## Typographie suggérée

- **Police principale** : Inter, Roboto, ou system font
- **Taille de base** : 16px
- **Titres** : 24px - 32px (h1), 20px - 24px (h2), 18px - 20px (h3)
